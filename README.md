# Web Scraping & Price Tracking

A Python web scraping project for extracting, storing, and monitoring product price data over time.

## Tools & Technologies
- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook

## Project Overview
This project collects product information and prices from a website,
stores the extracted data, and uses Pandas to process and track price changes over time.

## Project Files
- `Web Scraper Project_soha.ipynb` - Jupyter Notebook containing the scraping and data processing code.
